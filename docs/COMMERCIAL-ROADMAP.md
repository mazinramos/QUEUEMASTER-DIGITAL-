# خريطة البيع والتشغيل التجاري

## الصيغة التجارية المقترحة (قابلة للتغيير)
1. **تركيب لمرة واحدة:** جهاز العيادة، الراوتر، الإعداد، التدريب، وقالب علامة العيادة.
2. **اشتراك شهري/سنوي:** دعم، تحديثات، نسخ احتياطي، وتجديد الترخيص.
3. **خدمات إضافية:** تصميم محتوى إعلانات، رسائل SMS، مزامنة سحابية، تقارير مخصصة.
4. **مساحة إعلانية داخل العيادة:** تُباع لجهات خارجية مع تقرير إثبات عرض (proof-of-play).

## ما يجب أن يكون جاهزاً قبل أول بيع
- [ ] مثبّت Windows بنقرة واحدة (حساب 5) مجرَّب على جهاز نظيف.
- [ ] ترخيص لكل عيادة (حساب 1) وتجربته (صالح، منتهٍ، مزوَّر، بلا ملف).
- [ ] علامة العيادة من الأدمن (شعار، لون، اسم).
- [ ] صوت عربي مقبول (مقاطع مسجلة) (حساب 4).
- [ ] تصميم يجتاز المراجعة البصرية (كل الحسابات).
- [ ] وضع عرض تجريبي (Demo) ببيانات واقعية ومحاكاة حركة (حساب 5).
- [ ] وثائق: دليل التركيب، الشبكة، المستخدم، النسخ الاحتياطي، سياسة الخصوصية، اتفاقية الخدمة، عرض المبيعات (حساب 5).
- [ ] تجربة ميدانية أسبوع في عيادة واحدة قبل البيع الموسّع.

## مخاطر معروفة يجب إدارتها
- الاهتزاز غير مدعوم على iOS؛ التنبيه يعتمد على النغمة والإضاءة وSMS الاختياري.
- كاميرا مسح QR والإشعارات وWake Lock تتطلب سياقاً آمناً (HTTPS أو localhost): الحل HTTPS محلي (حساب 1 + 5).
- الصوت العربي عبر المتصفح يختلف بين الأجهزة: الحل مقاطع مسجلة.
- أجهزة Windows بإصدارات Node جديدة قد تفشل في بناء الحزم الأصلية: يُثبَّت إصدار Node ويُشحن مع المثبّت.
- خصوصية: أرقام الهواتف مؤقتة ومشفرة، وتُحذف بعد المدة.

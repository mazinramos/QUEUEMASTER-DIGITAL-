# الحساب 3 — واجهة المريض + واجهة الموظف + المكوّنات المشتركة
**الفرع:** `acct-3-patient-staff`  |  ابدأ فوراً على العقود، واربط بالباك إند عند جاهزيته (لا تضع بيانات وهمية في مسارات الإنتاج؛ لو احتجت محاكاة مؤقتة ضعها في ملف dev منفصل يُحذف قبل التسليم).

## قبل أي شيء
1. اقرأ بالترتيب: `README.md`، `docs/SPEC-SUMMARY.md`، `docs/workflow.md`، `docs/architecture.md`، `docs/database.md`، `docs/api-contract.md`، `docs/socket-events.md`.
2. اعمل على فرعك فقط، وفي ملفاتك فقط (جدول الملكية في `architecture.md`).
3. نفّذ ملفات حقيقية واختبرها فعلياً. لا أزرار وهمية، ولا إعلان اكتمال قبل الاختبار.
4. ارفع شغلك على فرعك باستمرار، وافتح Pull Request نحو `main` عند كل مرحلة، وأضف تقريراً في `reports/acct-N/` من `reports/TEMPLATE.md`.
5. البيئة: Node 20+، Windows 11 هو هدف الاختبار (مسارات متوافقة، لا أوامر bash فقط في scripts؛ وفّر بدائل npm scripts).

## المهام
### المرحلة 1: `web/shared/` (أنت مالكه، ويستخدمه حساب 4 و5)
- `tokens.css`: ألوان (كحلي عميق، أخضر طبي، نعناعي، أبيض/رمادي فاتح)، مسافات، خطوط، ظلال خفيفة، بلا تدرجات مفرطة.
- خطوط عربية ولاتينية **محلية** (ملفات woff2 داخل الريبو، لا CDN: النظام يعمل offline). مثلاً IBM Plex Sans Arabic + Inter.
- `i18n.js`: ar (افتراضي) و en، تبديل اللغة مع `dir` و`lang` على `<html>`. تصميم RTL وLTR مقصود باستخدام CSS logical properties، وليس مجرد قلب.
- `api.js` (fetch wrapper مع CSRF والأخطاء)، `socket-client.js` (إعادة اتصال، تجاهل eventId المكرر)، أيقونات SVG بأسلوب Lucide محلية.
### المرحلة 2: بوابة المريض `web/patient/`
- ترحيب، اختيار الخدمة (مع عدد المنتظرين)، إصدار التذكرة، شاشة نجاح "تم إصدار تذكرتك بنجاح"، التذكرة الرقمية (الرقم، الخدمة، الوقت، QR، الحالة الحية، من قبلك، الانتظار المقدر).
- حفظ كصورة (canvas)، PDF قابل للطباعة (نافذة طباعة أو توليد بسيط بدون مكتبات ثقيلة)، مشاركة عبر `navigator.share` مع بديل، إدخال رقم الهاتف **اختيارياً** لطلب SMS، حفظ التذكرة في `localStorage` وإعادة فتحها لاحقاً، استرجاع التذكرة، تحديث حي عبر Socket.IO مع Polling احتياطي، معالجة انقطاع الاتصال برسالة واضحة.
- لا حسابات، لا بيانات شخصية. يعمل جيداً على الهواتف العادية.
### المرحلة 3: لوحة الموظف `web/staff/`
- تسجيل الدخول والخروج وانتهاء الجلسة، اختيار الشباك، التذكرة الحالية، التالي، عدد المنتظرين، متوسط الانتظار.
- الأزرار: نداء التالي، إعادة النداء، بدء، إنهاء، تخطي، إرجاع، إلغاء، تحويل (تظهر حسب الصلاحيات فقط)، البحث/التحقق برقم التذكرة، ومسح QR بالكاميرا (`BarcodeDetector` إن توفر، وبديل بالإدخال اليدوي).
- تحديث حي، وكل زر حقيقي ويتعامل مع أخطاء `ALREADY_CALLED` و`INVALID_TRANSITION` برسائل مفهومة.

### قبول
- اختبار يدوي موثق + اختبارات DOM بسيطة للمنطق (إن أمكن). لقطات شاشة للهاتف بالعربية والإنجليزية في التقرير.
- لا اعتماد على أي مورد خارجي. تباين وقابلية قراءة جيدة. حجم الأزرار مناسب للمس.

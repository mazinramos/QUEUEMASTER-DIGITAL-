QueueMaster design system

Rules: no emoji, no coloured boxes with coloured borders, no side-accent cards, no decorative gradients or blur. Status is text, icon and a dot in the status colour on the page itself; strong emphasis is one solid fill with white text. Spacing 4/8, two radii, one icon set (Lucide, stroke 1.75, 24 grid), motion uses only transform and opacity and respects prefers-reduced-motion. Change the brand colour above: only buttons and highlights move, status colours do not.

Colour

Brand is the only injected value (--brand, via QM.brand.apply). The action colour is derived so white text on it is always at least 4.5:1.
